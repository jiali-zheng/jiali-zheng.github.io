DigitalMe: A Large-Scale Real-World 3D Garment Dataset

Overview

DigitalMe is a large-scale real-world 3D garment dataset introduced for realistic garment modelling, reconstruction, and generation. The dataset contains high-resolution 3D scans of clothed humans and is used to train Design2Cloth, a 3D garment generative model that produces detailed garments from simple 2D visibility masks.

DigitalMe is designed to address the limitations of synthetic or small-scale garment datasets by providing real-world clothing geometry with realistic wrinkles, folds, and fabric deformations.

Key Features

  • 2,010 subjects
  • More than 2,000 garments
  • 31 garment categories
  • High-resolution 3D clothed human scans with approximately 150,000 vertices
  • Real-world garment wrinkles, folds, and surface details
  • Diverse body shapes, poses, clothing styles, and garment categories

Dataset Statistics

DigitalMe contains garments from 31 categories, including T-shirts, shirts, blouses, hoodies, trousers, skirts, dresses, jackets, coats, sweaters, and other everyday garment types.

The dataset follows a realistic, non-uniform distribution across garment categories. Frequently worn garments such as sweaters, hoodies, and short-sleeve T-shirts are more strongly represented, while less common categories such as asymmetric garments, long dresses, gowns, and highly fashion-specific garments are underrepresented.

The data was primarily collected during colder seasons, which introduces a seasonal bias toward winter and layered clothing. This improves the realism of the collected data but should be considered when evaluating performance on rare, summer-specific, or formal garments.

Data Format

Each sample may include the following data:

  • 3D garment mesh, e.g. .obj or .ply
  • SMPL body parameters, e.g. .pkl
  • 2D visibility masks, e.g. .png
  • Optional rendered views for visualisation and evaluation

Usage Examples

Garment meshes can be loaded using standard mesh processing libraries such as trimesh. 

import trimesh

mesh = trimesh.load("path/to/mesh.obj")
mesh.show()

Visibility masks can be loaded as standard image files. 

from PIL import Image
import matplotlib.pyplot as plt

mask = Image.open("path/to/mask.png")
plt.imshow(mask, cmap="gray")
plt.axis("off")
plt.show()

Recommended Evaluation Protocol

To support reproducible comparison, we recommend evaluating garment reconstruction and generation methods using a standardised protocol.

Train / Test Split

  • Use a fixed training and test split.
  • Perform splitting at the subject level where possible to avoid identity leakage.
  • Report results on the same held-out test set for fair comparison.

Metrics

  • Chamfer Distance (CD): evaluates geometric reconstruction error.
  • Normal Consistency (NC): evaluates agreement between predicted and ground-truth surface normals.

Evaluation Setup

  • Evaluate garments in canonical space.
  • Uniformly sample surface points from predicted and ground-truth meshes.
  • Use the same number of sampled points for all compared methods.
  • Report results separately for reconstruction, generation, and interpolation tasks where applicable.

Benchmark Tasks

  1. 3D garment reconstruction from 2D masks
  2. 3D garment generation from latent space
  3. Interpolation between garment styles and shapes
  4. In-the-wild garment reconstruction from image-derived masks

Known Limitations

Although DigitalMe provides large-scale real-world 3D garment data, several limitations should be considered when using the dataset.

  • The category distribution is non-uniform and reflects real-world collection conditions.
  • Everyday and winter garments are more strongly represented than rare, formal, or highly fashion-specific clothing.
  • Some garment categories, such as asymmetric designs, cut-out garments, long gowns, and thin-strap clothing, are underrepresented.
  • Some scans may contain minor reconstruction artifacts due to the acquisition and processing pipeline.

These factors may affect model generalisation, particularly for out-of-distribution garment types. Results on rare or underrepresented garments should therefore be interpreted with this distributional bias in mind.
